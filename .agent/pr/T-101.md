# T-101 Tool registry + policy gate

Spec: `docs/specs/assistant.md` §3, §4, §8 (1–3). Branch `agent/brain`, on top of T-100 (`c75f72d`).

## Changes
- `supabase/core/supabase/migrations/20261108090000_ai_tool_gate.sql`
  - `core.ai_tool_rate` (private: RLS on, no policies, no grants): per lane, user and fixed window call counter.
  - `core.ai_tool_gate(p_lane, p_view, p_category, p_limit, p_window_seconds)` (security definer, empty search_path, authenticated only; not anon, not service_role). For `auth.uid()` only, in order: aal2 → membership → role (admin_technical denied) → lane enabled → `lane_policies.llm_allowed_categories` → 'assistant' view + required view (`core.allowed_lanes`) → rate limit (atomic; denied calls do not count). Returns `{allowed, reason, role}`, never data. Definer because finance_operator cannot read `core.lane_policies`.
- `packages/ai/src/tools/registry.ts`: `ToolDescriptor` per spec, `createToolRegistry()`. Registration refuses non-strict objects at any depth, any field named like "lane" at any depth, open-ended schemas (record, any, unknown, transform, pipe, …), unknown category/view/effect/resultStore, bad names, duplicates. `llmTools(categories)` emits JSON Schema (`additionalProperties: false`).
- `packages/ai/src/tools/gate.ts`: `createPolicyGate({registry, requireLane, audit, rateLimit?})`. laneId comes from the server; `requireLane` (core guards) → `core.ai_tool_gate` RPC with the user's client → strict arg parse → `withAudit` run. Denials return `{ok:false, reason, message}` with fixed model-facing text and are audited as `assistant.tool_call.denied` (reason, tool_use_id, category, effect; no argument values). Defence in depth: only owner/finance_operator roles accepted from the DB reply. Tool errors become `tool_failed` with no error text. Audit failure before the run means the tool never runs. Never throws.
- Exports `@nichols/ai/tools` (server-only). `zod` and `server-only` added to packages/ai (allowlist updated; `server-only` was imported by T-100's fix and must be a declared dependency under strict pnpm).
- `050_catalog.test.sql`: `core.ai_tool_rate` on the private list; `core.ai_tool_gate` on the definer and authenticated-exec lists.
- DB types regenerated.
