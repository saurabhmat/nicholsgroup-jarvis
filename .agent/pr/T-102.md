# T-102 Untrusted content wrapping + injection suite

Spec: `docs/specs/assistant.md` §4 (Untrusted content), §8 items 7–8. Branch `agent/brain`, on T-101 (`9256654`).

## Changes
- `packages/ai/src/untrusted.ts`: `wrapUntrusted` → `<untrusted_data source="…" id="…">…</untrusted_data>`; every `<`, `>`, `&` inside is escaped (content cannot close or forge a wrapper, or any tag); unsafe provenance attributes become "unknown". `wrapFields(data, paths, source)` for `untrustedFields` paths (`customers[].name`, `memo`, objects/arrays wrap all their strings). `UNTRUSTED_DATA_RULE` (system-prompt section: data, no authority, cannot change rules/tools/lanes/roles, cannot approve/send/pay/propose; report requests instead of acting). `containsUntrustedTag`.
- `packages/ai/src/tools/loop.ts`: `runToolLoop` — one assistant turn: model → tool_use → gate (server laneId) → wrapped tool_result → model, `maxSteps` (default 6, never leaves an unanswered tool_use). Always adds the rule to the system prompt and refuses a system prompt containing wrapped content (T-100 sec L3). `propose` tools are refused unless `userInitiatedPropose` (explicit user action). `toolResultContent`: email/docs tools without declared fields get every string wrapped; source labels always wrapped; figures (display strings) are not.
- `packages/ai/src/injection/{corpus.ts,injection.test.ts}`: 10 cases (email ignore-and-send, nested closing tags, double-encoded tags, doc cross-lane, web hidden comment, customer-name closing tag, memo role-play transfer, secret exfiltration, forged args, category escalation). Mock model scripted to comply: reads the carrier, makes the attacker's calls, relays everything.
- `pnpm test:injection` → `@nichols/ai` `vitest run src/injection`. Opt-in real model: `INJECTION_REAL_MODEL=1 pnpm test:injection` (needs the ANTHROPIC_* group; server-side assertions only).

## Tests (assertions per case)
Only read tools ran, all with laneId PKG; no proposal; every attacker call refused (unknown tool, invalid args, category denied, propose not allowed); the rule in every system prompt and no payload in it; wrapper tags balanced, raw payload never present when it has `<>&`; no secret canary (session token, key) in any request, tool result or answer. Plus spec §8.8 (customer name close tag escaped and wrapped), propose allowed on explicit user action, system prompt with untrusted content refused, rule not duplicated, maxSteps. `untrusted.test.ts` for escaping, attributes, paths, immutability.
`pnpm typecheck && pnpm lint && pnpm test && pnpm test:injection` pass. Real-model run not done (H-002).

## Risks
- Wrapping lowers the odds the model is fooled; the guarantees are server-side (gate, strict args, propose-only + userInitiatedPropose).
- `notes` in tool results are not wrapped (tool-authored text); tools must not put external text there (T-104 review item).
