# T-000 Make next-task.mjs honour `needs:`

**Stacked on `agent/plan-pilot`.** Merge the plan PR first, or retarget this PR to `main` after it.

## Summary
- `scripts/next-task.mjs` skips approved tasks whose `- needs:` items aren't checked (`- [x]`) under `## Needs human`. Unchecked or unlisted ids count as unmet. The `depends:` behaviour is unchanged.
- Parsing **fails closed** using an allowlist grammar:
  - **Task blocks:** only `- status:`, `- depends:`, `- needs:` and `- acceptance:` are allowed, each once. `status` and `depends` are required, `-` means none, and an empty value is an error. Any other line blocks that task, and the reason shows in `--explain`.
  - **Whole-file errors** print nothing on stdout and exit 1:
    - code fences anywhere
    - task fields outside a task block
    - a task heading inside Needs human
    - duplicate task ids or Needs-human items
    - anything other than exactly one `## Needs human` heading
  - A malformed task never counts as done.
- `--explain` lists every approved task as ready or blocked, with the reasons. An optional path argument selects the backlog file (default `docs/backlog.md`).
- `scripts/run-backlog.sh` now stops with exit 1 when next-task fails. Before, `|| true` turned a backlog error into "No approved tasks ready".

## Tests
34 `node:test` tests. They cover the acceptance cases (met, unmet, unknown and multiple needs; deps + needs; file order; `--explain`) and one case per review finding: repeated fields, duplicate ids, malformed tokens, wrong-form field lines, orphan fields after headings or rules, code fences, the Needs-human section rules, and a malformed done task. Two CLI tests check exit codes and that stdout stays empty on errors.

## Risks
- The stricter grammar means any new line type in a task block (e.g. a future `- spec:` field) blocks that task until `FIELD` in `next-task.mjs` allows it. This is intentional and visible via `--explain`.
- A whole-file error now stops `run-backlog.sh`. That is intended, but an unattended run will halt until the backlog is fixed.
