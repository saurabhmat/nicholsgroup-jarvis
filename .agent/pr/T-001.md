## Release-age gate (Next version)
pnpm 12 refuses to install packages published within its `minimumReleaseAge` window, which is 1 day here. next@16.4.3 and eslint-config-next@16.4.3 were published on 2026-10-23, about 5 hours before this build. The first install therefore added a `minimumReleaseAgeExclude` list to `pnpm-workspace.yaml`.

**Outcome:**
- `next` and `eslint-config-next` are pinned to **16.4.2** (published 2026-10-15), the newest 16.x release that passes the gate.
- The exemption list is **removed**.
- The lockfile was regenerated from a fresh resolution. Every `@next/*` package resolves to 16.4.2, and there are no 16.4.3 entries left.
- Nothing in this task needs 16.4.3, so no exemption or follow-up was required. Moving to 16.4.3 or later is a normal dependency bump once it is older than the window.

## Security review
One review, as the dev-tooling policy requires. **No BLOCKER, no HIGH.**

**Checked and fine:**
- All 454 lockfile entries come from registry.npmjs.org and have sha512 integrity hashes. There are no git, tarball or http sources.
- No package may run install scripts (`allowBuilds: { unrs-resolver: false }`).
- `.env*` files are still ignored at any depth, with `.env.example` the only exception.
- `turbo.json` passes no environment variables through, and no remote cache is configured.

**Findings:**
- **M2, the release-age exemption:** resolved by the 16.4.2 pin above.
- **Logged as follow-ups** in `docs/plan-review.md` §6:
  - **M1:** the `test:db` and `test:injection` placeholders pass green.
  - **M3:** `supabase/.temp/` is ignored only at the repo root, which matters once T-006 adds `supabase/core`.
  - **L1:** `turbo` is a `^2` range, not a pin.
  - **L2:** Turbo and Next telemetry are on by default.
  - **L3:** build outputs could hold build-time env values if a remote cache is ever enabled.
  - **L4:** notes on `next.config.ts` for production.
  - **L5:** `.claude/settings.local.json` isn't gitignored.
  - **L6:** two files have 0600 permissions locally, which has no effect in git.
