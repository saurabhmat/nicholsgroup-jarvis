## Risks
- The trigger and the function now decide the limit: lowering it never changes a row (tested).
- An older deployment reads the new config key as malformed and pauses Teams: the limit SQL runs only after the deploy (the SQL refuses unless DEPLOYED is typed).
- Chat clicks still re-read both lists (T-296).
