# T-273: fflate 0.8.2 to 0.8.3 (AI Brain .zip import could freeze the browser tab)

Approved by Saurabh on Nov 23, 2026.

## Why
The AI Brain import reads the chosen .zip in the person's browser with fflate's streaming `Unzip` (`apps/web/lib/import-files.ts`, called from the client component `brain-import.tsx`). fflate 0.8.2 loops forever on a local file header that carries the ZIP64 size marker (`0xFFFFFFFF`) with no ZIP64 extra field (GHSA-px8p-9vwx-vf98). That happens while parsing the header, before the import's own limits run (10 MB file, 200 entries, inflate caps).

A crafted file under 1 KB therefore froze the tab of whoever imported it. The file is never parsed on the server, so there was no server, data or cross-company impact.

## Changes
- `apps/web/package.json`: `fflate` 0.8.2 to 0.8.3, an exact pin as before. `pnpm-lock.yaml`: that one package changes, with its registry integrity hash.
- `apps/web/lib/import-files.test.ts`: two tests.
  - The pinned fflate is 0.8.3 or later.
  - The crafted header gives `{ ok: false, error: "unreadable" }` in under 2 seconds. This test is skipped on an older pin: there the call never returns, and a synchronous loop cannot be timed out by the test runner.
- `docs/backlog.md`: T-273 added; T-272 set to done (PR #66 merged).
- No app code changed.
