# T-023: App shell and lane switcher

## Summary
Authenticated layout under `/[laneId]/...`: navy side menu on desktop, navy header band plus bottom tabs on iPhone, company switcher limited to lanes that are enabled, served and allowed (aal2), placeholder routes for every module, lane in the URL verified on the server on every layout and page. Scope changes from Saurabh (Nov 4) included: Projects is shown (between Assistant and Settings; under More on iPhone) and the shell is light/dark aware.

## Changes
- `packages/core`: `LaneRouter.listLanes(session)` (user client, RLS on `core.lanes`, intersected with ENABLED_LANES and the core data plane, so a listed lane is one `getLaneClient` opens; a failed query throws, never an empty list); `Guards.listLanes()`; `laneSegment()` and `laneVerdict()` for the proxy; `LaneSummary` type. No SQL.
- `packages/ui`: `AppShell`, `LaneSwitcher`, nav-as-data in `lib/nav.ts` (`NAV_ITEMS`, `MOBILE_TABS`, `MORE_ITEMS`; T-024 edits this table), `lib/theme.ts` (system/light/dark, `data-theme` on `<html>`, pre-paint script, localStorage only). Tokens only; dark values are Saurabh's commit 4a17d71.
- `apps/web`: `app/[laneId]/layout.tsx` + pages (home, finance, inbox, calendar, approvals, assistant, projects, settings, more), `lib/lane-page.ts` (`loadLane`: requireLane + listLanes, 404 for unknown/disabled/non-member alike, redirect for no session/AAL1), `/` redirects to the first allowed lane (or "no company access"), `not-found.tsx`, `components/shell.tsx` (usePathname + Next Link), `theme-toggle.tsx`, `proxy.ts` early 404 for a refused lane, theme init script in the root layout.
- Choice documented: refused lane = **404** (not 403) so lane existence is not leaked.
- Approvals badge slot exists (prop), hidden until the approvals module supplies a count. No "Sample data", no "All companies", no Search/Commitments.
