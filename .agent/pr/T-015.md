# T-015: Audit API (TypeScript)

## Changes
- `@nichols/core/audit` (`packages/core/src/audit/`):
  - `createAudit(sink).log({laneId, actor, action, target, metadata})`: validates the entry (lane code, actor user|service|system with a uuid for users, dotted action, target ≤ 300), redacts the metadata, and calls the sink with the `audit.log()` arguments. The sink performs the database call; the lane router (T-016) provides it.
  - `redactMetadata()`: drops credential- and content-named fields in any case style (token, secret, password, api key, authorization, cookie, session, body, content, text, message, subject, snippet, prompt, notes, ...; `input_tokens` and `idempotency_key` are kept), replaces secret-looking values (env secret patterns, any JWT), truncates strings at 200, depth 4, arrays 50, about 8 KB in total.
  - `withAudit(audit, entry, action)`: writes the entry first; if that fails, the action does not run (AuditError). Errors never carry the database message, which can quote the row.
- Tests: `audit.test.ts` (11).
