# T-022: UI foundation (Tailwind + shadcn/ui + packages/ui)

## Summary
- **shadcn/ui set up in `packages/ui`** (monorepo layout, Tailwind v4): `components.json` in `packages/ui` (css: `src/styles/theme.css`) and `apps/web` (css: `app/globals.css`), `tailwind.config` empty, aliases `@nichols/ui/components`, `@nichols/ui/lib/utils`, `cn()` helper (clsx + tailwind-merge), shadcn-style `Card`, `Badge`, `Button`, `Alert` primitives using `class-variance-authority`.
- **Theme from the provisional design tokens v2** (`docs/plan-review.md` §7) in `packages/ui/src/styles/theme.css`: CSS variables on `:root` (shadcn semantic names + `gold`, `gold-foreground`, `alert*`, `success*`, `sidebar*`, `divider`, `primary-hover/tint`, `accent-italic`, radii 8px/12px, content max-width 1200px) mapped through `@theme inline`. Components use token utilities only, so D-20 edits the values in `theme.css` and the matching token-value assertions in `packages/ui/src/styles/tokens.test.ts` (nothing else). No dark mode (undecided until D-20).
- **Components** (all take pre-formatted display strings from props; no data fetching; server-component compatible):
  - `KpiCard` — label, tabular-nums figure, optional qualifier ("month to date"), `bookBalance` flag, `status` `ok | pending_definition | no_data` with overridable text (e.g. "Pending definition (D-3)"), source chips, footer slot.
  - `SourceChip` / `FreshnessBadge` — source, live/cached/stale (text, not colour only), "as of" with optional `<time dateTime>`.
  - `LaneChip` — lane code with optional name (tooltip + screen-reader text).
  - `BookBalance` / `BookBalanceLabel` / `BOOK_BALANCE_LABEL` — fixed "Book balance" label (not relabelable), figure in tabular numbers.
  - `EmptyState` (role=status), `ErrorState` (`role` "alert" by default, "status" allowed).
  - `ErrorBanner` — source-agnostic page-level banner (`role` "alert"/"status") with optional `action` slot and optional "Contact support" mailto (strict address check, sanitised subject). Built here because it sits naturally on `Alert`; T-197 can use it with `supportEmail="it@pub-k.org"`.
- **apps/web**: depends on `@nichols/ui`, adds it to `transpilePackages`, `globals.css` imports Tailwind + `@nichols/ui/theme.css` and `@source`s the UI package; root layout swaps Geist for Inter + Source Serif 4 via `next/font/google` (downloaded at build time and self-hosted; no browser requests to Google). No pages, shell or navigation (wait on D-20); the create-next-app placeholder page is unchanged apart from removing its `dark:` classes.

## Security self-review
- No `dangerouslySetInnerHTML`, no HTML strings; all props render as React text (tested).
- `ErrorBanner` only builds a `mailto:` for a strict plain-address pattern: local part `[A-Za-z0-9._+-]` (no `%`, so percent-encoded payloads such as `%0D%0A`, `%2C`, `%3F`, `%40` are rejected), no `?`, CR/LF, spaces, quotes or `javascript:`; otherwise no link. The subject has control characters removed, is capped at 200 characters and is `encodeURIComponent`-ed. (The first version allowed `%` in the local part; fixed after review, see Review.)
- No runtime CDN/font loads: fonts are self-hosted by `next/font`. No data fetching or env access in `packages/ui`.
- The formal security and code reviews are run by the orchestrator after this build.

- `pnpm-lock.yaml` will conflict with other worktrees; regenerate on rebase.
