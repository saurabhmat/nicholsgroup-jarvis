# T-100: LLMProvider interface + Anthropic implementation

## Changes
- `packages/ai/src/types.ts`: `LLMProvider` (`modelFor(tier)`, `complete(request)`), tiers `analysis`/`fast`, typed results (`completed`, `tool_use`, `max_tokens`, `paused`, `refused` with category), `LLMProviderError` (code + retryable, fixed message), `LLMCallLog`.
- `packages/ai/src/anthropic.ts`: the only SDK import. Adaptive thinking or omitted; thinking-off sent as `between_tools` (rejected above effort high); never `disabled`, `budget_tokens`, temperature/top_p/top_k; `tool_choice` auto only; no prefill; effort via `output_config`; streaming via `.stream().finalMessage()` above 16k max tokens; SDK typed errors mapped by `instanceof`.
- `packages/ai/src/mock.ts`: scripted mock provider recording calls.
- `packages/ai/src/config.ts`: `getLLMProvider()` from `getAnthropicEnv()`; `{configured:false, missing}` when unset.
- `.env.example` model defaults `claude-sonnet-5-5` / `claude-haiku-5-5`; `@anthropic-ai/sdk` 1.6.0 added to packages/ai (allowlist test updated); vitest `server-only` stub in packages/ai.
