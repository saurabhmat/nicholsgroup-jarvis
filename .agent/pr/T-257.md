# T-257: Settings "Your Microsoft accounts", admin consent help and local Disconnect

`docs/specs/microsoft.md` §5.5, §7. TypeScript only: no SQL, no migration, no pgTAP change, no new dependency, no allow-list entry. One new package export (`@nichols/connectors/microsoft-settings`, a narrow server-only surface).

## Summary
Settings -> Connections now shows "Your Microsoft accounts" next to "Your Google accounts" (Google is unchanged) when Microsoft is enabled for the company: connect, reconnect per row, several accounts per user, other people's rows as health only (owner/admin_technical). A connection whose provider is not (or no longer) enabled is listed as "Paused: <Google|Microsoft> is not enabled for this company" with no Connect or Reconnect and its data kept. Microsoft gets a local Disconnect (D-55), an admin consent link, and fixed result texts. One `mailProviderSettings` read per page render decides which sections show (never `isMailProviderEnabled` plus a second read).

## Rule 5 (external writes)
Local Disconnect writes nothing to an external system: `microsoft/disconnect.ts` imports no HTTP client, token manager or guard and reads no token. Tests assert `fetch` is never called in the connector and in the route handler. That is why D-55 allows it without approvals, unlike the QuickBooks disconnect, which revokes at Intuit.

## Access and statuses (route `POST /api/lanes/<lane>/connections/<id>/disconnect`)
Cross-site 403; malformed lane or id 404; no session 401; AAL1 or a role without own_mail 403 (guard); other lane 404; another person's mailbox, another lane's connection or a non-Microsoft row 404 (same answer, so existence is not revealed); outage 503 with a fixed body.

## Risks
- The consent return branch is the only new unauthenticated path. It runs before the session check by design (the admin may not be signed in), does nothing but redirect, and cannot be reached by a request carrying a `code`.
- `adminConsentUrl` carries the lane's tenant id (from `lane_config`) to members who can connect; it is meant to be sent to an administrator.
- A failed providers read leaves Google as it was and shows a "Microsoft connection status is unavailable" notice (also in a lane that never used Microsoft).
- Disconnect leaves the grant at Microsoft in place (documented limitation, V-9); the end-user removal steps are unconfirmed and stay generic until H-070.
