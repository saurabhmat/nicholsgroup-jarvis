# T-240: Home top 5 (recency-aware), "Waiting on you" only when true, Home polish

## Changes
- **Ranking** (`packages/modules/briefing/src/domain/attention.ts`): top 5 holds only threads whose latest inbound message is within `lane_config.briefing.attention.fresh_hours` (default 48, 6..168). Order: importance band (VIP, Money/Deadline, waiting, unread, security, failures), then newest first. Older qualifying threads (priority/waiting/unread) are not ranked: Home shows "Still waiting: N older threads" (hidden at 0), linking to Inbox `?view=waiting` (new view, same ranking, metadata only).
- **Waiting on you**: `core.briefing_threads` returns `last_to_owner` (owner mailbox in To of the latest inbound message; boolean only). The chip needs it and no later owner reply; otherwise reason chips VIP / Money / Deadline (`briefing.deadline_subjects`, new). Reason texts no longer claim a reply is owed when it is not.
- **AI briefing**: gets the same fresh list, the older count as a number only, Eastern times; prompt forbids refs and UTC in sentences; deterministic `tidyContent` strips `(r4)` / `r6` and rewrites ISO/UTC to "9:42 AM ET" before masking and saving.
- **Polish**: attendees never named from a local part (event name, then name held for that exact address, else the address); own-domain newsletters excluded (derived own domains, `exclusions.own_domain_bulk_senders`); greeting by Eastern time (morning / afternoon / evening); sidebar brand wraps instead of clipping; slim QuickBooks strip (not connected / reconnect required) replaces the tile; note "Top 5 from the last 2 days".
