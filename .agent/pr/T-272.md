# T-272: Next.js security upgrade (16.4.2 to 16.4.6)

Approved by Saurabh on Nov 23, 2026.

## Why
`pnpm audit` listed seven advisories against `next` 16.4.2, all rated moderate and all fixed in 16.4.5 or later. The production build had started stopping once per run with Next's own notice about it. The advisories:
- cross-client response injection and disclosure in self-hosted apps;
- cross-user cache disclosure and poisoning in `use cache` with binary arguments;
- HttpOnly cookie exposure through an internal response header on Edge runtime routes;
- SVG rejection bypass in image optimization;
- two cache leaks across root param values in `use cache` functions;
- cache poisoning of shared fallback shells in Cache Components.

This app uses Cache Components and partial prerendering, so the cache advisories are relevant to it.

## Changes
- `apps/web/package.json`: `next` and `eslint-config-next` go from 16.4.2 to 16.4.6, the current `latest`. Both are exact pins, as before.
- `pnpm-lock.yaml`: updated by `pnpm install`. No 16.4.2 package remains.
- No app code changed. It is a patch release within 16.4.
- `docs/backlog.md`: T-272 added. T-271 is set to done, with Saurabh's two decisions after the merge: Approvals and Assistant stay under Settings, and Claude and ChatGPT stay as new-tab links.

## Tests
- `pnpm typecheck`, `pnpm lint` and `pnpm test` pass (18 of 18 test tasks).
- `pnpm --filter @nichols/web build` succeeds on "Next.js 16.4.6 (Turbopack)" with no security notice. `scripts/check-build-log.mjs` finds no clock or prerender error in the build log.
- `pnpm audit` after the upgrade: no advisory for `next`. Three moderate ones remain for other packages (see Risks).
- **Not run:**
  - Playwright (e2e).
  - `pnpm test:bundle`, the secret-canary scan of a real build. It refuses to run while `apps/web/.env.local` exists, and that file was left alone.

## Risks
- **Patch-release behaviour changes.** The fixes change how Next keys and shares cached output. Nothing in the unit tests or the build changed, but the real proof is production: Home, Finance, Settings and a company switch, each as two different users.
- **Remaining audit findings, not fixed here (all moderate):**
  - `fflate` 0.8.2, a direct dependency of `apps/web`, used to read uploaded AI Brain .zip files. A malformed ZIP64 archive can make `unzipSync` loop forever. Fixed in 0.8.3. This one is worth its own small task, because it reads files a user uploads.
  - `glob` and `minimatch`, both transitive: `glob` through `inngest`'s OpenTelemetry packages, `minimatch` through lint tooling. Neither is on a request path of the app.
