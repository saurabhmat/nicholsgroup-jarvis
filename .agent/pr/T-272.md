# T-272: Next.js security upgrade (16.4.2 to 16.4.6)

Approved by Saurabh on Nov 23, 2026.

## Why
`pnpm audit` listed seven advisories against `next` 16.4.2, all rated moderate and all fixed in 16.4.5 or later. The production build had started stopping once per run with Next's own notice about it. The advisories:
- cross-client response injection and disclosure in self-hosted apps;
- cross-user cache disclosure and poisoning in `use cache` with binary arguments;
- HttpOnly cookie exposure through an internal response header on Edge runtime routes;
- SVG rejection bypass in image optimization;
- two cache leaks across root param values in `use cache` functions;
- cache poisoning of shared fallback shells in Cache Components.

Which of them apply to this app (security review, Nov 23, 2026):
- **Applies:** the fallback-shell poisoning in Cache Components. `next.config.ts` sets `cacheComponents: true`, and the pages under `[laneId]` use partial prerendering.
- **Do not apply today:**
  - The `use cache` advisories: the app has no `use cache` or `unstable_cache`.
  - The Edge cookie advisory: no route runs on the Edge runtime.
  - The SVG advisory: the app does not use `next/image`.
  - The self-hosted advisory: the app runs on Vercel.

Upgrading is still right for all of them.

## Risks
- **Patch-release behaviour changes.** The fixes change how Next keys and shares cached output and fallback shells. Nothing in the unit tests or the build changed, but the real proof is production: Home, Finance, Settings and a company switch, each as two different users.
- **Remaining audit findings, not fixed here (all moderate):**
  - `fflate` 0.8.2, a direct dependency of `apps/web`. The AI Brain import reads the chosen .zip **in the person's browser** with fflate's streaming `Unzip` (`apps/web/lib/import-files.ts`, called from the client component `brain-import.tsx`). The file is not parsed on the server.
    - A crafted zip under 1 KB with a ZIP64 size marker makes the parser loop forever, before the 10 MB, 200-entry and inflate limits run.
    - The impact is a frozen browser tab for the person importing it. There is no server, data or cross-company impact.
    - Fixed in 0.8.3. Proposed as its own small task.
  - `glob` and `minimatch`, both transitive: `glob` through `inngest`'s OpenTelemetry packages, `minimatch` through lint tooling. Neither is on a request path of the app.
