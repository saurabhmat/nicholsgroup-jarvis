## Review fixes (Nov 8, 2026)
Security review: 1 HIGH, 2 MEDIUM; code review: 2 HIGH, 9 MEDIUM. Fixed:
- Sec H1 (route never checked assistant access): new `core.ai_chat_turn(p_lane)` (definer, migration `20261108110000`) runs before any model work: aal2, role owner/finance_operator with the 'assistant' view in an enabled lane, non-empty categories → else 403. pgTAP 262 (viewer, admin_technical, outsider, cross-lane, AAL1, disabled lane, no-category lane). `runChatTurn` also refuses empty categories (no model call).
- Sec M1 (cost amplification): per-user, per-lane turn limit in the same function (6/min, `lane_config.assistant.turns_per_minute` 1..60) → 429; total history capped at 24,000 characters (route) / 20,000 (client).
- Sec M2 + code M8 (grounding false passes/alarms): only money/percent figures in tool data or the user's conversation count; ids and timestamps never; values normalised (`$1.50` = `$1.5`).
- Sec L1/L2: content-length checked before reading, byte length enforced; JSON content type and `Sec-Fetch-Site: same-origin` required. Sec L3: `core.ai_tool_categories` limited to owner/finance_operator (pgTAP adds disabled lane). Sec L5: meetings `refs_only`. Sec L7: chips `prefetch={false}`.
- Code H1: text from separate model steps separated by a blank line; prompt says no text before tool calls. Code H2: history built from complete (question, answer) pairs, failed/stopped/empty answers dropped as pairs (`lib/assistant-client.ts`, tested).
- Code M1 (DST days) and M2 (all-day events by `start_date`) fixed with tests. M3: chips grouped (3 per source, then "+N more" to the list page) with date and freshness. M4: 401 → session message. M5: stream ending without `message.done` shows "cut off"; malformed frames skipped; trailing buffer flushed. M6: 16px input on iPhone, auto-scroll, re-focus, safe-area padding, New chat moved to the header. M7: plain-text formatting rule in the prompt. L3 provider-neutral "Calendar" label; L5 aria-live only on the progress line; L6 date when not today.

Deferred: one in-flight stream per user; grounding from trusted figure fields only (required before T-104); chips limited to sources the answer used; Playwright; history from the server once T-103 exists (sec L6).
