## Changes
- `supabase/.../20261108100000_ai_tool_categories.sql`: `core.ai_tool_categories(p_lane)` (definer, authenticated only): the caller's `llm_allowed_categories` when aal2 + member + 'assistant' view + not admin_technical, else `{}`. pgTAP `261` (cross-lane, viewer, admin, AAL1, outsider). Catalog lists updated.
- `packages/ai/src/tools/catalog.ts`: `list_recent_mail` (email/comms, metadata via `core.inbox_messages`, no bodies) and `list_meetings` (calendar, `core.home_meetings`, New York day windows incl. DST), both through `ctx.client` (user's lane client, RLS). Only tool-formatted times are trusted; subjects, senders, titles, locations are wrapped. Sources link in-app (`/PKG/inbox/<id>`, `/PKG/calendar`). To move into comms/calendar modules with T-123/T-133.
- `packages/ai/src/chat.ts` (`@nichols/ai/chat`): strict request (alternating plain-text turns, ≤20 × 4,000 chars, no extra fields: no laneId, no tool results replayed), system prompt (static rules + `UNTRUSTED_DATA_RULE` cached + typed dynamic line), `runChatTurn` on `runToolLoop` (maxSteps 6, no proposals), events `message.start · text.delta · tool.start · tool.result · citations · grounding · message.done · error`, numeric grounding check (money and percentages must appear in this turn's tool data; flagged, no retry yet).
- Result envelope: `sources[].url` may be https or an in-app path (`/[A-Za-z0-9_/-]`).
- `apps/web/lib/assistant.ts` + `app/api/lanes/[laneId]/assistant/route.ts`: POST SSE. Body ≤100 kB and schema-checked before the session; guards (AAL2 + lane) → 401/403; `not_configured` 503 when the ANTHROPIC group is incomplete; categories from SQL; policy gate with audit (`getAudit`) on every tool call; abort on disconnect (`request.signal`); errors carry a code only, logs the class only.
- `apps/web/components/assistant-page.tsx` + `assistant-chat.tsx`: replaces the placeholder. Disabled states (not configured / no categories). Suggestions, streaming answer, tool progress line, source chips (in-app links only), unverified-figure badge, Stop, New chat. Text rendered as React text with `**bold**` only (no HTML). Conversation in component state only.
- `apps/web` depends on `@nichols/ai` (allowlist + transpilePackages).
