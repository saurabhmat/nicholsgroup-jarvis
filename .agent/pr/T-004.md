## Proposed additions (for a human to apply to `.github/workflows/ci.yml`)
- **gitleaks:** a secret scan on every PR.
- **turbo cache:** a cache of `.turbo` keyed on the lockfile and commit.
- **concurrency:** cancels superseded runs on the same PR.
- **timeout:** a job time limit.
- **Lighthouse:** left for T-025 (the PWA), which doesn't exist yet.

```diff
 name: CI
 on: [pull_request]
+concurrency:
+  group: ci-${{ github.event.pull_request.number }}
+  cancel-in-progress: true
+permissions:
+  contents: read
 jobs:
+  secrets:
+    runs-on: ubuntu-latest
+    steps:
+      - uses: actions/checkout@v4
+        with: { fetch-depth: 0 }
+      - uses: gitleaks/gitleaks-action@v2
+        env:
+          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
   checks:
     runs-on: ubuntu-latest
+    timeout-minutes: 30
     steps:
       - uses: actions/checkout@v4
       - uses: pnpm/action-setup@v4
       - uses: actions/setup-node@v4
         with: { node-version: 22, cache: pnpm }
       - uses: supabase/setup-cli@v1
+      - uses: actions/cache@v4
+        with:
+          path: .turbo
+          key: turbo-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}-${{ github.sha }}
+          restore-keys: |
+            turbo-${{ runner.os }}-${{ hashFiles('pnpm-lock.yaml') }}-
       - run: pnpm install --frozen-lockfile
       - run: pnpm typecheck
       - run: pnpm lint
       - run: pnpm test
       - run: pnpm test:db          # starts local Supabase and runs pgTAP RLS tests
       - run: pnpm test:injection   # prompt-injection suite (from phase 2)
```
If turbo isn't configured with `--cache-dir=.turbo`, point `path` at `node_modules/.cache/turbo` instead. A gitleaks run on a private repo of an organization may need a `GITLEAKS_LICENSE` secret.
