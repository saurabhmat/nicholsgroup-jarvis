## Why `limit_to_enabled_modules` and not "just read `enabled_modules`"
`enabled_modules` was never read by any code, and PKG's production list may be incomplete (production-pkg-lane-config.sql wrote `assistant, comms, calendar, brain`
as version 1). Reading it strictly would hide Finance, Approvals and Projects for PKG on deploy. With the flag, PKG does not change. If you prefer strict
reading, first add the modules to PKG's list by a new version, then flip the default (one line in `moduleVisible`).
