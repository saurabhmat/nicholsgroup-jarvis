- `effectivePermissionsByLane` (each lane's own policy and role) and `kpisForLane` (never a KPI from another lane) for multi-lane employees (sec M3, code M3).
- `approvals.expire_after_hours`: a legacy `email.draft`-only value is copied to `email.save_draft`; two different values are refused (code M1, sec L3).
- IANA time zone check; no control characters in `include`/`topics`; unique `days`/`delivery`/`exclude`; `email.draft` stored as `email.save_draft`; lane_config's mailbox spelling stored; `unknown_type` and `lanes_duplicate` codes; frozen tables.
