# T-210 Brain module + schema

## Summary
Adds the AI Brain foundation (Phase A14, spec `docs/specs/brain-and-employees.md` §3, §7a): schema `brain` with owner-only RLS and security-definer writers, a new `packages/modules/brain` package (domain, server store, jobs), the seed templates (moved from `docs/brain-templates/`), and the hourly import-candidate purge. No UI, no interview, no prompt assembly (T-211+).

## Changes
- **Migration** `supabase/core/supabase/migrations/20261107090000_brain_schema.sql`: `brain.documents`, `document_versions`, `employees`, `skills`, `imports`, `import_candidates` (non-null `lane_id`, timestamptz, RLS: AAL2 + allowed lanes; About-Me/Preferences and imports/candidates owner-only; candidates hidden after 24 h; no user DML, service_role has no brain writes). Writers: `brain.document_save` (optimistic `if_version`, 0 = create; no-op on identical text; keeps the last 20 versions; secret scan), `brain.employee_save`, `brain.skill_save`, `brain.import_decide`; each checks aal2, owner role, ownership. Secret scan also as CHECK constraints. `'brain'` added to `core.view_names()` (owner only). Thin invoker wrappers `core.brain_*` because `brain` is not an exposed schema. `core.brain_import_purge(lane)` (service_role only; deletes candidates older than 23 h, closes imports open after 24 h).
- **Package** `packages/modules/brain`: `domain` (paths/kinds, `containsSecret` reusing `looksLikeSecretValue`, `resolveHomeLane` with no hard-coded lane, templates), `server` (`createBrainStore({ clientFor })`: read/save helpers through the lane router client, `ensureSeeds` lazy seeding), `jobs` (`createImportPurge`), `tools`/`ui` placeholders. Added to `scripts/dependency-allowlist.test.mjs` (and `apps/web` for the job wiring).
- **Core**: `'brain'` in `MODULES`; Inngest `brain-import-purge` (hourly `7 * * * *`, one step per enabled lane) wired in `apps/web/app/api/inngest/route.ts`.
- **Templates** moved to `packages/modules/brain/templates/` (bundled by `scripts/build-templates.mjs`; a test fails when stale); `docs/brain-templates/README.md` now points there. Spec §3 got an implementation-notes block.
- Retention: version pruning inside `document_save`; candidates by their own hourly purge (plan-review finding 19: not a T-042 day class); comment in the T-042 table list.
