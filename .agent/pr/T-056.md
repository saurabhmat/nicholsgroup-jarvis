# T-056 QuickBooks normalizer -> fin.*

## Summary
`core.fin_qbo_normalize(lane, connection)` turns the raw QuickBooks records of one connection (`raw.source_records`, written by T-051) into `fin.accounts`, `fin.invoices`, `fin.bills`, `fin.payments` and `fin.transactions`, entirely in SQL (money `numeric(18,2)` parsed and rounded once, dates, `timestamptz`). It is idempotent (a re-run changes nothing, `updated_at` included), never deletes, tags every row with its entity from `lane_config`, and records each run in the new `fin.normalize_runs` (counts, class-tracking state and the QB-10 fallback, full-reload cutoff, reallocations as ids). It runs automatically after a QuickBooks `conn.sync`.
