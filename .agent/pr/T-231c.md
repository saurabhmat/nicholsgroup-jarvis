# T-231c: Home briefing — AI daily briefing job + "Run now"

Branch `agent/T-231` (on top of T-231a, T-231b and the T-233 merge). Full security + code review done; every BLOCKER and HIGH fixed (see `docs/plan-review.md` → "T-231c review follow-ups").

## Changes

SQL — `supabase/core/supabase/migrations/20261111120000_brief_briefings.sql`:
- New schema `brief`, table `brief.briefings` (`lane_id`, owner, trigger `manual|schedule`, status `ready|partial|failed`, review window, `content`, `coverage`, `source_refs`, model, `prepared_at timestamptz`). RLS: the owner reads their own rows only (AAL2, allowed lane, briefing view). Insert trigger `brief.briefings_guard` checks that the owner is a lane owner with the briefing view, and refuses reply drafts unless `store_outbound_drafts`.
- `core.briefing_latest(lane)`: the newest non-failed briefing, plus a flag when a newer attempt failed.
- `core.briefing_save` (service_role, scheduled job) and `core.briefing_save_own` (authenticated "Run now": AAL2, owner, own uid, cooldown `too_soon`).
- `brief.briefings_purge` / `core.briefings_purge`: retention (floor + 30-day cap, enabled lanes only), registered in the retention registry as `brief.briefings`.
- Catalog test updated (`050_catalog`); `packages/core/src/db/types.ts` regenerated.

Code:
- `packages/modules/briefing/src/domain/compose.ts`: prompt rules, JSON extraction, grounding (whole figures, dates in either order, ISO dates), masking of amounts and long digit runs (rule 7), content checks (ungrounded lines dropped; nothing verified → partial).
- `packages/modules/briefing/src/jobs/index.ts`: save / save-own / owners / purge; takes explicit clients (no service client in this module).
- `packages/core/src/inngest/briefing-daily.ts`: `briefing.daily` hourly cron (`5 * * * *`); a lane runs only when `lane_config.briefing.schedule_enabled` is set (default **off**) and it is the lane's briefing hour in New York.
- `apps/web/lib/briefing-run.ts`: one run. Live reads of the top threads (bodies never stored, untrusted, wrapped as data) gated by the lane's `llm_allowed_categories`; owner's Personal Assistant profile from the brain ("Run now" only); writes Today's briefing, upgraded Needs your attention (what/why/next), Deadlines and follow-ups, Top 3 priorities.
- `apps/web/lib/briefing-schedule.ts`: due owners (membership + views re-checked every run) and the scheduled run.
- `apps/web/app/api/inngest/route.ts`: wires the job and the retention entry (the only place the job client is created).
- Home: `run-briefing-button.tsx`, `briefing-actions.ts` (server action), `home-ai-briefing.tsx`, with "prepared at", the review window, and a note when a newer attempt failed; `maxDuration` 90 on the Home page.
