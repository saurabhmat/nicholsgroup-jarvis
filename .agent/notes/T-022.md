# T-022 notes
- Tailwind 4.3.3 (CSS-first, no tailwind.config); shadcn monorepo layout: `packages/ui/components.json` + `apps/web/components.json`, `tailwind.config: ""`, styles in `packages/ui/src/styles/`.
- Tokens: `packages/ui/src/styles/theme.css` `:root` holds the provisional v2 values (plan-review §7) under shadcn semantic names plus Nichols extras (gold, alert, success, sidebar, radii, content width); `@theme inline` maps them to utilities. Raw names that would collide with Tailwind namespaces are `--heading-font`, `--body-font`, `--control-radius`, `--card-radius`. D-20 changes values only.
- Fonts: apps/web uses next/font/google (build-time download, self-hosted) for Inter and Source Serif 4, exposed as `--font-inter` / `--font-source-serif-4`, consumed by the theme with fallbacks.
- Components are server-compatible (no hooks, no "use client"), take display strings only, no fetching.
- Tests: jsdom + Testing Library; tokens.test.ts checks every token value, WCAG contrast of each text pair, and scans component sources (no hex colours, no raw gold text, no dangerouslySetInnerHTML, no "bank balance").
