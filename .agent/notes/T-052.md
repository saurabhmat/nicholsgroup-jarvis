# T-052 QuickBooks Reports API - notes

Plan / design
- Pure part `quickbooks/reports.ts`: `planReports` (dates in America/New_York from `lane_config.finance.reports.period`, method, class) and `projectReport` (strict Zod allowlist, FLATTENED rows `{type: Header|Data|Summary, level, group?, ColData[{value,id?}]}`, label masking, aging names dropped, payroll rows/sections removed). `reports-job.ts` runs one connection: settings + payroll first (fail closed), one Account query for the payroll classification, then fetch/project/store each of the five reports independently.
- Class filter: sent only when `conn.features.class_tracking` AND `REPORT_DEFS[kind].classFilter` (true for pnl, balance_sheet only; CashFlow and aging unverified -> false). Unsplit = no `class` in params, `unsplit` marker says why when classes were configured.
- Classes come from `entities.by_entity[own_entity].qbo_class_ids` in a `file_class` lane (`laneConfigReader.reportSettings`); period is the new `finance.reports.period`.
- SQL (migration 20261106090000): `fin.report_cache_guard` replaced (non-object raises 23514; string value with a letter and a 5+ digit run raises 22023; constant messages, no DETAIL); `core.fin_report_cache_put` (security invoker, service_role only, usable QuickBooks connection of the lane, upsert on the cache key) because PostgREST exposes core, not fin; no DB statement_timeout (role-wide alter removed; function-level SET does not bound its call; client abort 30 s instead). pgTAP 210 (80 tests) incl. cross-lane denial.
- Wiring: store `report-store.ts` (RPC, fixed errors), vault `reportCacheStore`, `@nichols/connectors/reports` entry (job + lister), core `inngest/fin-reports.ts` (nightly 02:00 ET schedule, event `fin/qbo-reports.requested`, concurrency 1 per connection, ENABLED_LANES check and event re-validation), route wiring.
- Fake Intuit: `/reports/:name` handler + `syntheticReports()` fixtures (nested BalanceSheet raw depth > 16, hazards: Option, MetaData, href, memo keys, digit runs, payroll section, aging names).
