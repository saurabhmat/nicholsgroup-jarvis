**Save:** propose an update to HANDOFF.md with the date, status, completed work with real locations, decisions, pending work and blockers, the next step, and what is verified vs unverified. Update BRIEF.md too if a decision changed requirements. Drafts are not approvals.

**Resume:** read BRIEF.md and HANDOFF.md, check that the sources they mention are connected now, summarise the state and next step. If the user only asked for status, give status.
